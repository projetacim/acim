# **App Name**: Association Manager

## Core Features:

- Member Management: Add, update, and delete member profiles, including contact information and membership status.
- Donation Tracking: Record and track donations made by members, including amount, date, and payment method.
- CERFA Generation: Generate CERFA forms (official donation receipt) automatically based on donation records.
- Simple Authentication: Password based Authentication for admins.
- Dashboard Overview: Display key metrics and summaries on a dashboard, such as total donations, active members, and recent activity.
- Automated Compliance: AI tool monitors donation patterns, flagging anomalies to ensure compliance with tax regulations, ensuring the right CERFA forms are automatically generated based on regional regulatory conditions. 

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and stability.
- Background color: Light gray (#F5F5F5), creating a clean and professional backdrop.
- Accent color: Teal (#009688), used sparingly for highlights and action items.
- Body and headline font: 'PT Sans' for a balance of modernity and readability.
- Clean, well-spaced layout with a clear hierarchy of information.
- Use clear and recognizable icons from a set like Material Design Icons to represent different functions and data points.
- Subtle transitions and animations to enhance user experience and provide feedback on actions.
